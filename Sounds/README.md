# 教程音效文件夹（Sounds/）

本目录存放新手教程的音效。**已内置全套 5 个音效**（WAV，16bit 44.1kHz，共约 130KB）。
**即使把这里清空，教程也不会报错** —— 此时全部音效自动回退为 Web Audio 实时合成。

## 内置音效

| 文件 | 触发时机 | 音色 |
| --- | --- | --- |
| `select.wav` | 在章节目录里划过 / 选中一个「目」 | 清脆「哒哒」双击 |
| `next.wav` | 点「下一步 →」、点目题开始上课、切下一章 | 轻快翻页（上滑） |
| `prev.wav` | 点「← 上一步」、返回、关闭 | 较低沉（下滑） |
| `complete.wav` | 完成一个「目」/ 通关一章 / 全课完成 | 上行音阶 C-E-G-C |
| `error.wav` | 点了未解锁的章节 | 低闷提示 |

## 换成自己的音效

直接用同名文件覆盖即可（**扩展名按 mp3 → ogg → wav 顺序探测**，所以放 `select.mp3` 会优先于 `select.wav`）。
文件名必须**小写**、且与上表完全一致。

注意事项：

- 单个文件建议 **< 50KB、时长 < 0.5s**（音效要短促，长了会拖沓）。
- 建议先做**峰值归一化**；播放音量在代码里另乘 0.55，太响的素材会突兀。
- 播放依赖浏览器用户手势解锁（代码已在 `pointerdown`/`keydown` 时 `resume()` AudioContext），正常点击不会被拦截。
- 音效总开关在 **设置 → 新手教程 · 引导课 → 教程音效**（默认开启，选择持久化到 localStorage）。

## 重新生成内置音效

本目录的音效由 `_merge_tmp/gen_all_sfx.py` 用 Python 标准库合成（无需任何依赖）：

```
python _merge_tmp/gen_all_sfx.py
```

## 改合成音色（不放文件也能调）

不放文件时走 `正式版v.4.65.html` 里的 `exTutSfxSynth(name)` —— 每个音效就是几行
`exTutSfxTone(起始时间, 起始频率, 结束频率, 时长, 波形, 峰值)`，改这里即可。
